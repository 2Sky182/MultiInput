MANUAL – Bedienungsanleitung
1. Installation und Start
	-Laden Sie die aktuellste Version des Programms herunter.
	-Entpacken Sie die ZIP-Datei in einen beliebigen Ordner.
	-Starten Sie das Programm durch Öffnen der Datei MousemuxOverlay.exe.
	-Beim Starten der Anwendung können Warnmeldungen des Virenscanners oder / und
	 von Windows Defender erscheinen. Wählen Sie im Fall des Windows Defenders zunächst 
	 „Weitere Informationen“ und anschließend „Trotzdem ausführen“.
	-Falls die erforderliche Windows Desktop Runtime noch nicht installiert 
	 ist, folgen Sie den Anweisungen im angezeigten Informationsfenster, um 
	 die benötigte Komponente zu installieren und das Programm anschließend nochmal
	 zu starten.
2. Bedienung
	Nach dem Start der Benutzeroberfläche stehen Ihnen folgende Funktionen 
	zur Verfügung:
	-Multiinput.exe stoppen/starten: Über diesen Button können Sie das Programm 
	 anhalten und anschließend wieder starten.
	-Hide Cursor: Über das Feld in der unteren rechten Ecke können Sie den nativen 
	 Windows-Mauszeiger ein- oder ausblenden.
3. Systemvoraussetzungen und Hinweise
	-Das Programm ist ausschließlich für die x64-Architektur ausgelegt.
	-Unterstützt werden Betriebssysteme ab Windows 10.
	-Die Datei MultiInput.exe ist theoretisch nicht eigenständig ausführbar. Sie 
	 funktioniert nur, wenn sie über MousemuxOverlay.exe gestartet wird.
	 
------------------------------------ACHTUNG------------------------------------------

Das Programm funktioniert nicht in virtuellen Maschinen, es wird lediglich der Cursor 
versteckt ohne einen neuen zu rendern.
